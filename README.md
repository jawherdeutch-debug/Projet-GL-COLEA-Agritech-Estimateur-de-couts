Projet Jira – COLEA Agritech : Estimateur de coûts PolyBloom
1. Présentation du projet
Objectif : développer une plateforme web simple permettant aux huileries d'estimer le coût du traitement de leurs margines (Zibar) par la technologie PolyBloom de COLEA Agritech.
L'utilisateur pourra :
•	Saisir la quantité d'huile d'olive produite.
•	Estimer le volume de margines généré.
•	Indiquer la distance entre l'huilerie et le site de traitement.
•	Calculer le coût du transport et du traitement.
•	Obtenir une estimation du coût total.
•	Générer un devis simplifié au format PDF.
Type de projet Jira : Scrum
Nom du projet : COLEA – PolyBloom Estimator
Durée : 6 semaines
Nombre de sprints : 3 sprints de 2 semaines
Objectif : développer un POC (Proof of Concept / preuve de concept).
